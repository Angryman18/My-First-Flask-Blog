# My-First-Flask-Blog
This is my very first flask blog. and very simple

before you run this blog make sure you create a database because i have pulled admin data and page contents (about page or staff) from the MySQL database.

#Database Setting:
1. you can change your database setting if localhost or staff in config.json file.
2. change your email and password to yours own so that you can received email from your blog (contact us page).

3. Created Database named: bootstrap_blog
4. create 4 table named: a) admin b) data_control c) posts d) contacts (create as the same is written)
now you please open data_control.py and main.py to see what columns are there.

you install the required module to run this application,

PyMySql, flask_mail, flask, flask_sqlalchemy

i had used xampp to run mysql server
